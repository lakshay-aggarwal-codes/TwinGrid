## Residual gaps — not fixed here (outside the FE-19 allowance or needing a decision)

1. `src/components/FloorHeatmap.tsx` is still in the snapshot, unreferenced, and contains a `useFrame` loop. FE-08's
   own gate (`components/analyticsGate.test.ts`, "FloorHeatmap is deleted") says it must not exist, so that test should
   currently fail. Deleting it is the fix and also closes the "every `useFrame` loop honours reduced motion" item, but a
   deletion is not an ARIA/focus change, so it was left for you to approve.
2. `index.css` keyframes (`.pulse-dot`, `.scan-line`) have no reduced-motion guard; no component uses them. Add a global
   `@media (prefers-reduced-motion: reduce)` block or delete them (CSS is outside this task's allowance).
3. The Analytics bar chart still encodes mode by colour; only the summary/table carry it. A pattern/legend would be a
   visual change → logged as a design issue, not redesigned.

## How to produce the evidence

```
npm run verify
E2E_VIEWER_USERNAME=... E2E_VIEWER_PASSWORD=... npx playwright test e2e/a11y.spec.ts
```

Each axe scan attaches `axe-<label>.json` (all impacts) to the Playwright report; the gate is zero serious/critical.

Screen-reader notes (manual, NVDA or VoiceOver) — **not done**; record one line each: open/close a panel; Ctrl+K palette;
rack arrow traversal with the selection announcement; stale → reconnecting → connected announcement; chart summary +
"View data table" on `/analytics`.
