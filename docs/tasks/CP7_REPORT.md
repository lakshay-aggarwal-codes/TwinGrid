# CP-7 report: RAG intent, evidence and citations

**Status: delivered early at your request. Core done and tested here; the items under "Not done" are open.**

## What changed
- `src/copilot/docs_answer.py` (new): routing cues (strong "runbook/documentation/docs", weak "how do I ...", live-state
  guard), `DocsRetriever` (loads the CP-6 index, re-checks it against the documents at most every 60 s, treats a missing or
  stale index as unavailable), passage excerpting and `defang` (links, angle brackets, `{{ }}`, `[E#]` lookalikes removed).
- `src/copilot/answer.py`: new intent `docs_question` (last in `INTENTS`); `Answer.citations`; keyword routing first, then
  retrieval. Empty retrieval on an explicit docs question gives the honest "does not document an answer" answer; empty
  retrieval on a weak cue falls through to the existing intents. A missing or stale index never cites anything and adds
  `docs_index_unavailable` / `docs_index_stale` (only for an explicit docs question). `classify()` is unchanged.
- `src/copilot/evidence.py`: source `doc_passage` (value cap 400, entity cap 120); `tools.py`: `ToolContext.docs_search`
  (not a tool; `TOOLS` is unchanged).
- `src/copilot/llm.py`: for docs evidence, an extra policy paragraph and a grounding check (`ungrounded_text`): words the
  model types itself must all occur in a passage, evidence label, the draft or a short framing list. Tolerance is 0 and is a
  PLACEHOLDER for CP-9. This is a lexical guard, not a proof of faithfulness: an invented fact built only from passage words
  passes. Non-docs answers are unchanged (same system policy, same checks, same order).
- `src/copilot/schemas.py`: `Citation`, and `AskResponse.citations` (required list). `api/plugins/copilot.py` wires the
  shared retriever and returns `citations`. `twin-stream-insight-main/src/features/assistant/schema.ts`: source
  `doc_passage` and optional `citations`. `docs/api/openapi.json`: spliced from pydantic's own schema (method checked
  against the committed `Link`, `Limits` and `EvidenceItem`), not generated by FastAPI.
- Tests: `tests/test_copilot_rag_answer.py` (51 new). CP-0 files changed on purpose: the 22 goldens now carry
  `"citations": []` (checked: nothing else in them changed); `test_intents_golden.py` knows the 7th intent; `conftest.py` and
  one test ignore CP-2's `copilot_llm_chain` log line (without that, 39 CP-0 tests failed after CP-2 because my helper
  counted it). `tests/test_copilot_api.py`: the two exact key-set assertions now include `citations`.
