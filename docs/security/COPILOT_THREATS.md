# Copilot threat table (CP-8)

Scope: `POST /api/copilot/ask`, the docs retrieval index, and the optional model providers. Every row names the test that
checks its mitigation (`tests/test_copilot_hardening.py`, `tests/test_copilot_policy.py`). A mitigation without a test is
not listed. This table is checked by `test_the_threat_table_has_its_columns_and_every_evidence_test_exists`.

| Asset | Attack | Mitigation | Evidence | Residual risk |
| --- | --- | --- | --- | --- |
| Answer integrity | A document says "ignore previous instructions" or similar | Cues are detected (`sanitize.injection_cues`); the passage is quoted as marked data and no model may rephrase that answer (`docs_passage_flagged`) | `tests/test_copilot_hardening.py::test_a_poisoned_passage_is_quoted_as_inert_data_and_never_shown_to_a_model` | Cue list is lexical: a paraphrased or non-English instruction is not detected. The text is still only quoted, never executed |
| Answer integrity | A document forges `{{E#}}`, `[E#]`, the `BEGIN_DATA`/`END_DATA` delimiters or chat tokens | Removed by `sanitize.neutralize` before the text enters evidence or the prompt; the prompt block is JSON-encoded | `tests/test_copilot_hardening.py::test_neutralize_removes_every_control_marker` | Unknown template tokens of a future model family are not on the list |
| Answer integrity | Unicode tricks: zero-width characters, full-width look-alikes | NFKC normalisation and removal of invisible characters before every check | `tests/test_copilot_hardening.py::test_normalize_drops_invisible_characters_and_folds_width` | Letters from other alphabets that look like Latin ones (Cyrillic "a") are not mapped |
| Users of the UI | A document carries HTML, script or links | Angle brackets and links removed from passages, headings and paths | `tests/test_copilot_hardening.py::test_a_poisoned_heading_is_neutralised_too` | The frontend must keep rendering answers as text (not checked here) |
| Answer integrity | A model obeys a poisoned passage and invents facts, links or a "normal" status | `llm.validate` rejects unbacked numbers, links, forbidden wording and words not found in a passage | `tests/test_copilot_hardening.py::test_a_model_that_obeys_a_poisoned_passage_is_rejected_by_the_validator` | The grounding check is lexical: an invention built only from passage words passes |
| Alert text, ids, user names | Sent to a third-party provider that may train on prompts | Per-intent rule: cloud providers serve `docs_question` only unless the operator lists more (`COPILOT_LLM_CLOUD_INTENTS`) | `tests/test_copilot_policy.py::test_default_policy_answers_an_alert_question_rule_based_and_never_calls_a_cloud_provider` | An operator who lists an intent accepts that its reduced request goes to that provider |
| Alert text, ids, user names, raw values | Leaks through the request body of an allowed cloud call | Reduced request: no alert id, alert text or timestamps; question scrubbed; numbers withheld; leak check fails closed | `tests/test_copilot_hardening.py::test_no_request_to_a_cloud_provider_holds_an_identifier_alert_text_or_raw_value` | A free-text question can hold other personal data the scrub does not recognise (names of people other than the user) |
| Everything the user types | Operator wants no data to leave the machine | `COPILOT_LLM_LOCAL_ONLY=true` removes every provider not flagged local | `tests/test_copilot_hardening.py::test_local_only_sends_nothing_to_a_remote_host` | "Local" is the operator's flag: a remote server flagged local is trusted |
| Server capacity | Many slow model calls fill the worker threads | At most `COPILOT_LLM_MAX_CONCURRENT` chains run; the rest are answered rule-based at once; a slot is held until its thread ends | `tests/test_copilot_policy.py::test_a_second_slow_question_is_answered_rule_based_at_once_when_the_limit_is_one` | The limit is per process. The existing `state` rate limit (30/min per user) is shared with other state routes and was not changed |
| Response size | A large answer or many citations | Answer clipped, at most 3 passages, bounded request model | `tests/test_copilot_hardening.py::test_the_response_stays_small_in_the_worst_case` | None found for size |
